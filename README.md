# Applied Economics & Data Science Portfolio

Projects from my Master in Applied Economics and Data Science, using real-world data in R and Python.
**Author:** Daniela Borja Polanco

| Project | Question | Tools |
|---|---|---|
| [SDG 10.1.1 shared prosperity](projects/sdg-10.1.1-shared-prosperity) | Has income growth been inclusive, i.e. has the bottom 40% grown faster than the average? (51 countries) | R |
| [Growth accounting for Japan](projects/Japan_Growth_Accounting) | Which input explains Japan's postwar growth slowdown: capital, labour or TFP? | R Markdown |
| [Digital connectivity and income inequality](projects/digital-connectivity-inequality) | Is digital connectivity associated with within-country changes in income inequality? | R (fixest, plm, did, MatchIt): panel fixed effects, difference-in-differences, matching |

Independent projects are in [economics-projects](https://github.com/danielaborjap/economics-projects).
